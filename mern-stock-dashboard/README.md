# Antigravity AI Stock Dashboard (MERN Edition)

A high-performance stock prediction system rebuilt with MongoDB, Express, React, and Node.js.

## Architecture
- **Frontend**: React 18 + Vite + Tailwind CSS + Framer Motion (Antigravity UI).
- **Backend API**: Node.js + Express + Mongoose (Bridge to AI).
- **AI Microservice**: Python Flask (Logic from `D:\AI TRADE\stock_predictor`).
- **Database**: MongoDB (Local or Atlas).

## 🚀 Getting Started

### 1. Start the AI Microservice (Python)
```bash
cd ai-service
python app.py
```
*Runs on http://localhost:5000*

### 2. Start the Backend API (Node.js)
```bash
cd server
npm start
```
*Runs on http://localhost:5001*

### 3. Start the Frontend (React)
```bash
cd client
npm run dev
```
*Runs on http://localhost:5173*

## Features
- **Instrument Sans Typography**: Premium, legible font integration.
- **Glassmorphism UI**: Dynamic transparency and depth effects.
- **Real-time Pipeline**: Visualized "Feature Engineering & Sentiment" progress.
